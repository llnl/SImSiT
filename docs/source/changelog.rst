Version 1.0.0
=============

This release establishes the public SImSiT package as an image simulation
library for generating synthetic telescope images of stars and satellites.

Notable updates include:

- installable package and build configuration
- cleaned public-facing documentation
- example simulation configurations
- core modules for instruments, tracking, WCS construction, catalog access,
  and image generation
- reference output products for simulated images
- unit tests for core package functionality
